# **App Name**: صيدليتي (My Pharmacy)

## Core Features:

- Product Search: Enable product search using a search bar, with support for Arabic and English terms.
- Product Display: Display product information, including name, price, and available quantity. Support both Arabic and English display.
- Checkout: Implement a simple checkout process to calculate the total amount for the purchase.

## Style Guidelines:

- Primary color: Teal (#008080) to convey health and trust.
- Secondary color: Light gray (#D3D3D3) for backgrounds and less important elements.
- Accent: Gold (#FFD700) for highlights and important actions.
- Right-to-left layout support for Arabic language.
- Use clear and recognizable icons for product categories and actions.
